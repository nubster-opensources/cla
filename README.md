# Contributor License Agreement — Encelade Technologies

This repository contains the **Contributor License Agreement (CLA)** that applies to all open source projects published under the [`nubster-opensources`](https://github.com/nubster-opensources) GitHub organisation, owned by Encelade Technologies.

## Why a CLA?

A Contributor License Agreement is a standard mechanism used by open source projects (including those of Apache, Google, Microsoft, HashiCorp, Confluent, and the Linux Foundation) to formalise the licence under which contributions are accepted.

The CLA used here is a **License Grant**, not a copyright assignment:

- **You keep the copyright** on every contribution you make.
- **You grant Encelade Technologies a broad licence** to use, modify, sub-licence, and re-licence your contribution, including under different terms in the future (for example, dual-licensing or source-available licences for managed services).
- The version of your contribution distributed under the original open source licence (Dual MIT OR Apache-2.0) **remains perpetually available** under that licence.

This is the same model used by Apache projects, Google open source, and most commercially-backed open source projects.

## How to sign

Contributions submitted to any `nubster-opensources` project are checked by [CLA Assistant](https://cla-assistant.io/). When you open your first pull request, the bot will automatically:

1. Detect that you have not yet signed the CLA.
2. Comment on your pull request with a one-click signing link.
3. Record your signature against your GitHub identity.

Once signed, your signature applies to **all current and future contributions** to any `nubster-opensources` project. You only sign once.

## Notes for maintainers

- The CLA is intentionally kept in a separate repository so that it can be referenced from every project repository via a stable URL: `https://github.com/nubster-opensources/cla/blob/main/CLA.md`.
- Updates to the CLA must be discussed via pull request and announced to existing contributors.
- This repository will be made public at the same time as the first project transitions to public.
